# 🍉 Fruit App – E-commerce Mobile Application

**Fruit App** is an e-commerce mobile application built with **Flutter**, specialized in selling fruits online. It supports user authentication, product browsing, shopping cart management, and order processing via **PayPal**. The app is linked with a custom **admin dashboard** to manage products and handle orders.

## 🔐 Authentication Features

- **Email & Password login**
- **Phone number verification (OTP)**
- **Google sign-in**
- **Facebook login**
- Built on top of **Firebase Authentication**

## 🛠️ Backend & Data

- User and order data stored securely using **Cloud Firestore**
- Real-time product and order updates
- **PayPal** integration for secure payments
- Local user data persistence (name, address, etc.)
- Product images and data are managed via a connected **Dashboard project**

## 💡 Key Features

- Browse a wide selection of fruits with images, prices, and nutritional info
- Add to cart and place orders
- Authentication & user profile management
- Order and payment tracking
- Smooth animations and elegant UI
- Built using **Cubit** for clean state management


## 🎨 Technologies Used

- Flutter & Dart
- Firebase Auth
- Cloud Firestore
- PayPal API
- Cubit as state management
- shared prefernces as local storage 
- Custom animations
- Flutter Web Admin Dashboard (for management)
